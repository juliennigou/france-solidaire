# Politique de sécurité

## Signaler une vulnérabilité

N’ouvrez pas d’issue GitHub publique pour une vulnérabilité ou une fuite de
données potentielle.

Utilisez le bouton **Report a vulnerability** de l’onglet **Security** du dépôt
afin d’envoyer un rapport privé. Indiquez si possible :

- la partie concernée et l’impact potentiel ;
- les étapes minimales de reproduction ;
- une proposition de correction, si vous en avez une ;
- les éventuelles données personnelles exposées, sans les recopier.

Le rapport sera examiné avant toute publication. Merci de laisser un délai
raisonnable pour corriger et déployer le problème.

## Versions prises en charge

La branche `main` est la seule version actuellement maintenue. Les opérateurs
d’instances sont invités à suivre les mises à jour, sauvegarder PostgreSQL et
renouveler régulièrement les secrets d’application.
